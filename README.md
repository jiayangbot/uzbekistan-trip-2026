# Uzbekistan Trip 2026 — Timeline

Trang web local để xem timeline, khách sạn và lịch từng ngày (27 Oct – 9 Nov 2026).

## Chạy

```bash
npm install
npm run dev
```

Mở http://localhost:5179

## Build tĩnh

```bash
npm run build
npm run preview
```

Dữ liệu nằm trong `src/trip-data.js` — chỉnh file đó nếu cập nhật lịch hoặc giá quote.
